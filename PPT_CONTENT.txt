SLIDE 2 - THE PROBLEM
================================================================================
- Antibiotic resistance is a global health crisis
- Traditional culture & sensitivity tests take 24–72 hours
- Doctors prescribe antibiotics blindly while waiting
- Wrong antibiotics → treatment failure, longer stays, more resistance
- Goal: Predict resistance in < 1 second using patient data

================================================================================
SLIDE 3 - DATASET (MIMIC-III)
================================================================================
- Source  : MIMIC-III Clinical Database (ICU patients, 2001–2012)
- Size    : ~50,000 antibiotic susceptibility tests
- Features: 17 total
    - Demographics : age, gender, admission type, hospital outcome
    - Infection    : antibiotic code, organism code
    - Treatment    : total antibiotics, unique antibiotics, duration
    - Lab values   : BUN, creatinine, glucose, hemoglobin, platelets, potassium, sodium, WBC
- Classes : Susceptible (70%), Intermediate (10%), Resistant (20%)
- Key challenge: Class imbalance baked into the data

================================================================================
SLIDE 4 - DATA PREPROCESSING
================================================================================
- Missing lab values → filled with mean (mean imputation)
- Text converted to numbers:
    "VANCOMYCIN"        → 90012.0
    "STAPHYLOCOCCUS"    → 80002.0
    "EMERGENCY"         → 1
    "Male"              → 1, "Female" → 0
- All features standardized using StandardScaler
- Split: 80% training, 20% testing

SLIDE 8 - CLASS IMBALANCE PROBLEM & FIX
================================================================================
Problem:
- 88% of predictions = Susceptible
- 0% of predictions = Intermediate
- Root cause: Training data was 70% Susceptible

Solution — Adjustable Class Rebalancing:
    Before: S=98.67%  I=0.09%  R=1.24%
    After : S=95.35%  I=0.35%  R=4.30%

How it works:
    Susceptible penalty : × 0.5  (reduce confidence)
    Intermediate boost  : × 2.0  (increase sensitivity)
    Resistant boost     : × 1.8  (increase sensitivity)
    → Renormalize to 100%

SLIDE 9 - SYSTEM ARCHITECTURE
================================================================================
User (Browser)
     ↓
Web UI — Streamlit  (port 8501)
     ↓  HTTP POST /predict
REST API — FastAPI  (port 8000)
     ↓
ML Models (.pkl) — XGBoost / RandomForest / NeuralNetwork

3-tier architecture: Presentation → Application → Model

API Endpoints (7 total):
    POST /predict     → Run AMR prediction
    GET  /models      → List models + accuracy
    GET  /antibiotics → 30 supported antibiotics
    GET  /organisms   → 19 supported organisms
    GET  /health      → Health check
    GET  /metrics     → Prometheus metrics
    GET  /logs        → Prediction audit logs

SLIDE 14 - LIMITATIONS
================================================================================
- Intermediate class never predicted (0%)
- Trained on old data (2001–2012, single hospital — MIMIC-III)
- Balanced accuracy only 69.3% — misses 40% of minority classes
- No authentication or encryption (not HIPAA-ready)
- SHAP TreeExplainer has compatibility issues (falls back to feature importances)
- Not clinically validated — research/proof-of-concept only
- Only 30 antibiotics and 19 organisms supported
